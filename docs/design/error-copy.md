# Copy de errores

| Código | Español | Acción |
|---|---|---|
| invalid_path | La carpeta no es válida. | Elige una carpeta de Windows existente o usa Descargas. |
| access_denied | Windows no permite escribir en esta carpeta. | Elige otra carpeta o revisa sus permisos. |
| disk_full | No hay espacio suficiente. | Libera al menos 128 MB y vuelve a intentar. |
| browser_locked | El navegador está abierto o la sesión no se puede leer. | Cierra el navegador y vuelve a inspeccionar. |
| engine_unavailable | El motor de descarga no está disponible. | Reinicia la aplicación; la versión anterior se conserva. |

Nunca mostrar excepciones Python/Node directamente.
